# 🎉 تحديث: إضافة رفع الوسائط في المجتمع

## 📝 ملخص التحديث

تم إضافة إمكانية رفع **الصور والفيديوهات والصوتيات** في قسم المجتمع على الموقع، بحيث أصبح الموقع يوفر نفس الميزات الموجودة في تطبيق الموبايل.

---

## ✨ الميزات الجديدة

### 📸 رفع الصور
- رفع حتى **10 صور** في منشور واحد
- معاينة الصور قبل النشر
- حذف صور معينة قبل النشر
- دعم جميع صيغ الصور الشائعة

### 🎥 رفع الفيديو
- رفع فيديو واحد لكل منشور
- مشغل فيديو مدمج
- دعم التحكم بالتشغيل (play/pause/volume)
- دعم صيغ: MP4, WebM, OGG

### 🎤 رفع الصوت
- رفع ملف صوتي واحد
- مشغل صوت مدمج
- دعم صيغ: MP3, WAV, OGG

---

## 🚀 كيفية الاستخدام

### الخطوات:

1. **افتح صفحة المجتمع**
   ```
   https://your-domain.com/community_bonus
   ```

2. **اختر نوع الملف المراد رفعه:**
   - 📷 **صور**: اضغط على أيقونة الكاميرا
   - 🎥 **فيديو**: اضغط على أيقونة الفيديو
   - 🎤 **صوت**: اضغط على أيقونة الميكروفون

3. **اختر الملف من جهازك**

4. **شاهد المعاينة** وتأكد من الملف

5. **اضغط "نشر"** لنشر المنشور مع الوسائط

---

## 📋 القواعد والحدود

### الصور:
- ✅ حتى 10 صور في منشور واحد
- ✅ حجم كل صورة: حتى 10MB
- ❌ لا يمكن دمج صور مع فيديو أو صوت

### الفيديو:
- ✅ فيديو واحد فقط
- ✅ حجم حتى 50MB
- ❌ لا يمكن دمج فيديو مع صور أو صوت

### الصوت:
- ✅ ملف صوتي واحد
- ✅ حجم حتى 20MB
- ❌ لا يمكن دمج صوت مع صور أو فيديو

### عام:
- ✅ يمكن نشر منشور بوسائط فقط (بدون نص)
- ✅ يمكن نشر منشور بنص فقط (بدون وسائط)
- ✅ يمكن النشر المجهول مع الوسائط

## 🛠️ التثبيت والإعداد

## 🐛 استكشاف الأخطاء

### المشكلة: لا يمكن رفع الملف
**الحلول:**
1. تحقق من حجم الملف
2. تحقق من صيغة الملف
3. تحقق من صلاحيات المجلد
4. راجع console المتصفح للأخطاء

### المشكلة: الملف لا يظهر بعد النشر
**الحلول:**
1. تحقق من logs السيرفر
2. تحقق من قاعدة البيانات
3. تحقق من مسار الملف في `static/uploads/community/`

### المشكلة: "413 Request Entity Too Large"
**الحل:**
```python
# في app.py أو config.py
app.config['MAX_CONTENT_LENGTH'] = 100 * 1024 * 1024  # 100MB
```

## 📊 قاعدة البيانات

### الأعمدة المستخدمة في جدول `community_post`:

```sql
media_file_ids       TEXT     -- أسماء الملفات (JSON array)
media_types          TEXT     -- أنواع الملفات (JSON array)
media_preview_urls   TEXT     -- مسارات العرض (JSON array)
audio_file_id        VARCHAR  -- اسم ملف الصوت
audio_url            TEXT     -- مسار ملف الصوت
```

### مثال على البيانات:

```json
{
  "media_file_ids": ["1_20260714_123456_photo.jpg", "1_20260714_123457_photo2.jpg"],
  "media_types": ["image", "image"],
  "media_preview_urls": ["/static/uploads/community/1_20260714_123456_photo.jpg", "/static/uploads/community/1_20260714_123457_photo2.jpg"],
  "audio_file_id": null,
  "audio_url": null
}
```
